## 📖 Overview

The **Smart Billing System for Smart Trolley** is an embedded systems prototype that automates shopping cart billing using **RFID technology**.

Instead of manually scanning every product at the billing counter, each item is identified through an RFID tag. The system detects the product, processes its information through **Arduino Nano**, and instantly updates the bill on an **LCD display**.

This project demonstrates practical experience in **embedded programming, hardware integration, real-time processing, and prototype development**.

## ⚙️ Working Principle

The system performs billing through RFID-based product detection.

1. A product carrying an RFID tag is brought near the RFID reader.
2. The RFID reader detects the product's unique tag.
3. Arduino Nano processes the detected information.
4. The corresponding product details are identified.
5. The bill is updated instantly.
6. The LCD displays the latest billing information.
